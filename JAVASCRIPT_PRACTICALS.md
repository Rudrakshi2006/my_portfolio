# JavaScript Practical Concepts

This codebase deliberately uses JS and JSX for all application code. See `src/js-practicals/` and open the interactive **JavaScript Lab** from the footer.

- External JS: Vite entry, JS React components; also the lab script
- Inline JS: inline HTML button demo
- Internal JS: small inline script in index.html
- Console methods: lab console info/log/warn/error/table
- var / let / const, template literals, destructuring, user input: lab script
- if/else, switch, loops: lab script
- Form validation, form fields, regular expressions: lab script
- Function declarations/expressions/arrows, closures, scope: lab script
- try/catch: lab and App/session storage
- Arrays, array methods, objects, strings: portfolio data/filter features and lab
- DOM traversal, manipulation, event handling: lab
- localStorage and sessionStorage: lab and profile persistence
- JSON: portfolio data and lab
- fetch() API: live loading of project data from `public/project-catalog.json`
- jQuery & $.getJSON(): lab with jQuery loaded on its own page
- Dynamic rendering: React projects and laboratory cards

React handles most DOM updates declaratively; the separate lab showcases direct vanilla DOM access for academic demonstrations.
