# Rudrakshi Bhandekar — Cinematic JavaScript Portfolio

Original Netflix-inspired React/Vite look and animations preserved. Source application uses JavaScript/JSX, not TypeScript. All supplied projects, research, certificates, resume and social links included. DocFlow itself uses TypeScript, but this **portfolio** does not.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Edit content
`src/data/portfolio.js` contains the profile, project metadata, GitHub links, academic achievements and experience.

JavaScript examples are used throughout the website: arrays and `.map()`, objects, event callbacks, functions and arrow functions, template literals, destructuring, DOM rendered via React, browser sessionStorage, try/catch, async component loading and control flow. A standalone practical lab is not part of the site.
